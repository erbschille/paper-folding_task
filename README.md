# paper-folding_task
Paper Folding Task

This is a mental imagery outcome measure--intended to be given both pre- and post-experiment. This is a newly created digital version of the classic paper-and-pencil task*, coded in javascript with the assistance of Claude (model Opus 4.8 in June 2026).

**Collaborators or those interested in using this task should fork this repo. Please do not use our same link (it will mess with data collection)**

*Ekstrom, R. B., French, J. W., Harman, H. H., & Dermen, D. (1976). Manual for kit of factor-referenced cognitive tests. Princeton, NJ: Educational testing service.
